# 핀볼 사다리

이름이 **글자 모양 그대로** 떨어지는 핀볼형 사다리타기 파티 게임입니다.
큰 화면(PC)에서 방을 열고, 참가자는 폰으로 QR을 찍어 들어와 출발 위치와 장애물을 정합니다.
바닥의 **레이저 결승선** 칸을 통과하면 그 칸이 결과로 확정됩니다. 확정된 칸은 사라지고 이웃 칸이 자리를 메우기 때문에 한 칸에 두 명이 들어갈 수 없고, 판은 반드시 끝납니다.

- 최대 30명, 칸 30개
- 코스 두 가지: **긴 코스**(한 판 약 40초, 출발에서 오른쪽 아래로 흘러 내려가 결승선은 출발에서 40m 옆) / **짧은 코스**(긴 코스의 출발 부분만, 약 20초)
- 서버 없음: GitHub Pages(정적 파일) + PeerJS 공용 서버(`0.peerjs.com`)로 폰과 PC를 연결
- 물리는 PC에서만 돌고 폰은 컨트롤러 역할만 합니다

## 하는 법

1. PC에서 사이트를 열고 바닥 칸 이름을 적습니다. 줄바꿈이나 쉼표로 구분하고, `꽝*3`처럼 쓰면 같은 칸이 3개 생깁니다.
2. 코스와 1인당 장애물 수(0~5)를 정하고 **방 열기**를 누릅니다.
3. 참가자는 QR을 찍어 이름을 정하고, 보드를 끌어 출발 위치를 고르고, 장애물(벽돌, 트램펄린, 범퍼)을 코스 어디든 놓은 뒤 **준비 완료**를 누릅니다. 긴 코스는 폰 보드 오른쪽 코스 띠를 누르거나 끌어서 아래쪽으로 갑니다.
   - 폰이 없는 사람은 PC 대기실에서 이름을 추가하고, 보드에서 이름을 끌어 위치를 정할 수 있습니다.
4. PC에서 **시작**. 결과는 큰 화면과 각자의 폰에 동시에 표시됩니다.

## 긴 코스

출발에서 결승선까지 한 줄기로 이어진 코스입니다. 코스를 따라 차례로:

1. 엇갈린 핀, 풍차, 범퍼가 있는 출발 지점(짧은 코스는 여기까지)
2. 깔때기로 모여서 오른쪽 아래로 30m 내려가는 긴 미끄럼길. 바닥 점프대가 이름을 띄웁니다
3. 미끄럼길 끝에서 날아든 이름을 슈퍼 범퍼가 받아치고, 엇갈린 범퍼 네 줄
4. V자로 모이는 벽이 가운데 큰 시계추로 보내고, 아래로 좌우로 오가는 발판
5. 반대로 도는 원판 두 개, 그 아래 다이아몬드 섬이 길을 두 갈래로 나눕니다. 오른쪽 갈래 아래에서는 지름 12m 거대 풍차가 돌면서 내려온 이름을 왼쪽으로 쳐 냅니다
6. 결승선 바로 위에서 반대로 도는 풍차 둘이 이름을 좌우로 쳐내서 마지막까지 칸을 모릅니다. 벽 킥커가 풍차 쪽으로 밀어 넣어요

화면 연출:
- 시작 전 PC 화면은 보드를 크게 보여주고, 왼쪽 미니맵을 누르거나 휠·끌기로 코스 어디든 볼 수 있습니다(Ctrl+휠로 확대). '코스 둘러보기'를 누르면 카메라가 출발 지점에서 결승선까지 내려갑니다. 장애물은 각자 폰에서 놓습니다.
- 설정·대기실 창은 보드 위에 떠 있고, 접으면 방코드만 작게 남습니다.
- 네온 아케이드 그림: 빛나는 네온 벽, 이름이 부딪히면 번쩍이는 핀, 빛나는 이름과 꼬리. 길 바깥은 기계 바위로 채워져 길 모양이 보입니다.
- 세게 튀는 장치: 크고 세게 받아치는 슈퍼 범퍼, 이름을 띄우는 점프대, 벽 킥커, 거대 풍차. 튕길 때마다 큰 빛·불꽃·화면 흔들림
- 진행 중에는 보드가 화면을 다 쓰고, 오른쪽에 전원의 실시간 순위, 왼쪽 위에 미니맵(누르거나 끌면 그쪽을 잠깐 봄)이 붙습니다.
- 카메라가 이름이 가장 많이 모인 무리를 따라가며 무리 폭에 맞춰 확대합니다. 누군가 결승선에 가까워지면 아래 띠에 결승선을 따로 보여줍니다.
- 도착할 때마다 빛기둥·불꽃·'n등', 당첨 칸('꽝'이 아닌 칸)에 들어가면 화면 가득 당첨 연출.
- 참가자 폰에는 진행 중 내 순위와 진행 막대가 보입니다.

판이 끝나지 않는 일을 막는 장치:
- 2초 이상 끼이면 단계적으로 튕기기 → 장애물 통과 → 빈 곳으로 순간이동
- 7초 동안 더 내려가지 못하면(풍차에 실려 돌기 등) 잠깐 유령 상태로 빠져나감
- 45초 서든데스: 유저 장애물 전부 파괴
- 가속(짧은 코스 45초, 긴 코스 90초): 중력 1.6배
- 마무리(짧은 코스 75초, 긴 코스 120초): 남은 이름은 모든 충돌을 무시하고 떨어짐

## 30명 검증 결과

- 긴 코스: 30명 × 실제 글자 모양으로 5000판(장애물 무작위·길막 시도·한곳 출발 포함) 중 **안 끝난 판 0** (95% 신뢰 상한 약 0.06%). 보통 38~39초, 가장 길었던 판 62초. 90초 가속·120초 마무리까지 간 판은 0.
- 짧은 코스: 같은 조건 5400판 중 **안 끝난 판 0**. 보통 17~19초, 가장 길었던 판 34초.
- 이름이 잠깐 걸려서 자동으로 튕겨 주는 일은 거의 매 판 한두 번 있고, 순간이동까지 필요한 판은 6~10%입니다.
- 종단 테스트: PC 1 + 폰 30으로 두 판을 끝까지 진행, 전원이 자기 폰에서 결과를 받고 칸 중복 없음. PC 새로고침, 폰 네트워크 끊김, 폰 새로고침, 강퇴, 31번째 입장 거절까지 확인. 배포된 사이트에서 진짜 PeerJS 서버로 긴 코스 두 판도 통과(PC 약 54fps).

## GitHub Pages 배포

빌드 단계가 없습니다. 저장소 루트의 `index.html`, `src/`, `assets/`, `.nojekyll`이 그대로 사이트가 됩니다.

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main** / **(root)**
2. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`로 접속합니다.
3. 참가 QR은 이 주소에 `?room=방코드`를 붙여 자동으로 만들어집니다.

`file://`나 `localhost`로 열면 PC 화면은 확인할 수 있지만 폰에서는 들어올 수 없습니다.

구간 바닥·옆판·아이콘 그림은 `assets/`에 있습니다(Gemini로 만든 것, 없으면 코드로 그린 그림을 씀). 새로 만드는 법은 [assets/README.md](assets/README.md).

## 개발·테스트

```bash
npm install                       # planck, peerjs, qrcode-generator, playwright (테스트용)
npm test                          # 물리 헤드리스: 짧은 코스 200판 + 긴 코스 60판, fails=0 이어야 함 (sim.js 수정 후 필수)
npm run serve                     # http://localhost:8080
npm run e2e                       # 호스트 1 + 폰 30, 가짜 PeerJS로 두 판 진행 (Edge/Chromium 필요, --course short 가능)
npm run e2e:real                  # 진짜 PeerJS 서버 + WebRTC로 같은 시나리오
npm run stress                    # 긴 코스 30명 × 2000판 물리 스트레스 (stress:short는 짧은 코스)
node test/export-glyphs.js        # 브라우저에서 실제 글자 모양을 뽑아 test/fixtures/names.json 갱신
```

- `test/headless.js [판 수] [시드] --course long|short --players 30 --extra 0 --obs 2 --mode random|block --crowd`
- `test/fixtures/names.json`이 있으면 헤드리스 테스트가 합성 모양 대신 실제 글자 모양을 씁니다. `--synth`로 끌 수 있습니다.
- E2E 결과(스크린샷, report.json)는 `test/out/`에 저장됩니다.

## 알려진 제약

- PeerJS 공용 서버는 무료라 가끔 느리거나 불안정합니다. 회사·학교 방화벽에서는 연결이 안 될 수 있으니, 그럴 땐 폰 없는 사람 추가로 진행하세요.
- 게임 중에는 PC 브라우저 탭을 화면에 띄워 두세요. 탭이 가려지면 브라우저가 애니메이션을 멈춰 게임이 느려집니다.
- 장애물은 출발선 아래 코스 어디든, 다른 장애물 바로 옆에도 놓을 수 있습니다(겹치지만 않으면). 길을 막아도 벽돌은 3번 맞으면 부서지고, 끼인 이름은 장애물을 통과하고, 45초가 지나면 전부 부서져서 판은 끝납니다.
- "마블 룰렛"(lazygyu/roulette)에서 장르 아이디어를 얻었지만 코드, 맵, 그림, 이름은 별개입니다.
